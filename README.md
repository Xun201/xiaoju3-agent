# 小橘3号 (XiaoJu 3)

一个基于 Orange Pi 3B 的专属 AI 智能体，支持本地/云端双脑热切换，多通道记忆隔离，并接入 QQ 机器人与网页控制台。

## ✨ 核心特性

- **🧠 双脑架构**：本地优先使用本地电脑上的 qwen2.5:7b 模型，离线时自动无缝切换至 DeepSeek 云端大脑。
- **💾 记忆隔离**：网页控制台与 QQ 机器人拥有独立记忆库，互不干扰；并支持带密码保护的核心记忆库。
- **🔗 多端接入**：
    - **网页控制台**：可通过 Cloudflare 隧道实现 5G 外网访问。
    - **QQ 机器人**：基于 NapCatQQ 协议，支持私聊与群聊互动，具有防刷屏逻辑。
- **🛠️ 工具调用**：能够读写本地文件、抓取网页内容。
- **🎭 趣味功能**：支持收集群友表情包，以及基于关键词的自动回复。
