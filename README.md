# 小橘3号 (XiaoJu 3) 🤖

一个基于 Orange Pi 3B 的本地优先 AI 智能体，支持双脑热切换、多端接入、长期记忆、最高权限安全防护与个人日志提取。

## 🚀 核心特性
*   **双脑热切换**：本地 Ollama 优先，离线自动切换至云端 DeepSeek。
*   **多通道接入**：支持 QQ 群聊、私聊以及网页控制台。
*   **长期记忆与隔离**：网页端与 QQ 端独立记忆库，避免上下文污染。
*   **四层权限体系**：支持 Lv.1 游客、Lv.2 普通用户、Lv.3 代码编写者、Lv.4 最高权限（XUN）。
*   **动态密码安全防护**：最高权限采用 TOTP 动态密码 + 硬件指纹双重验证。
*   **全自动日志提取**：发链接即可自动抓取对话、切片总结并生成 Markdown 开发日志。

## 🛡️ 安全设计
*   **物理隔离**：核心数据与密钥文件存储在独立目录中，严禁上传。
*   **沙箱与白黑名单**：操作文件严格限制在白名单目录，拒绝访问敏感系统路径。
*   **审计日志**：所有权限激活与异常操作均有本地日志留痕。
*   **一键清理与死循环熔断**：内置异常捕获与自动熔断机制，保障长期运行稳定。

## 🛠️ 技术栈
*   **核心**：Python 3, Flask
*   **本地算力**：天选5（RTX 4060）+ Ollama
*   **云端算力**：DeepSeek API
*   **QQ 通道**：NapCat（Docker 部署）
*   **抓取与解析**：Playwright + BeautifulSoup

## 📦 快速部署
1.  克隆仓库：`git clone https://github.com/Xun201/xiaoju3-agent.git`
2.  配置环境变量：在隔离区创建 `config.py`，填入你的 API Key 与 NapCat 配置。
3.  安装依赖：`pip install -r requirements.txt`
4.  启动机器人：`python3 main.py` 或 `nohup ./start.sh > run.log 2>&1 &`
