## 二、录前检查表

### A. 环境（录前 30 分钟）
- [ ] 正式版在线：浏览器开 `http://127.0.0.1:5003/api/status` 返回数据（**exe 须含最新部署批**——控灯/家电链路在 10-05 夜版之后）
- [ ] 若 5003 拒连：双击 启动小橘3号.bat（正式版**开机不自启**，开机后须手动拉起）
- [ ] HA 可达：灯/插座实体可读；HA 网页开好**分屏**（拍实体状态翻转特写）
- [ ] Windows 暂停更新 24h（防录中强制重启）；通知免打扰（Focus Assist 开）
- [ ] 无痕窗口开控制台（无书签杂讯）；任务栏/桌面清理

### B. 演示件
- [ ] 小米灯实体在线（HA 里可读状态；提前确认灯的开关初态，分镜 5 要拍翻转）
- [ ] "演示空调" climate 实体在线（温度设定演示件）
- [ ] 待办面板预置 5-6 条不同优先级条目（分镜 3 画面不空）；账本已有记录
- [ ] Lv.4 已授权 + TOTP 有效（分镜 7 权限演示）；`CHILD_LOCK_ENABLED=true` 且儿童/成人双账号就位（完整版分镜 7；**双账号不便→用简化版**：主账号权限拒绝 + 物理开关两个动作，删儿童锁两句口播，省约 10s）
- [ ] 桌宠可见（分镜 1 同框；素材为占位图则镜头避开特写）

## 三、操作顺序卡（开录后按序执行）

1. 分镜 1：摆好同框画面（QQ 群 + 控制台 + 桌宠）→ 念开场词
2. 分镜 2：控制台发"数到三"→ 卡片生长全程 → 自动折叠后停 2 秒
3. 分镜 3：QQ 发链接 → 收到受理回复（拍下）→ 等提取完成 → 切面板拍分区/折叠/删除
4. 分镜 4：控制台发 /help → 菜单秒出 → 徽标特写 2 秒
5. 分镜 5：分屏摆好（左控制台右 HA 实体页）→ "打开小米灯" → 灯亮瞬间 HA 侧特写 → "把演示空调调到26度" → 温度变化特写
6. 分镜 6：先有网问一句 → 拔网线 → 再问一句 → 徽标"🏠 本地"特写 → 插回网线
7. 分镜 7：完整版三连（权限拒绝→儿童锁裁决→物理开关）或简化版（拒绝+开关）
8. 分镜 8：QQ 发 /soul_export → 拍回复
9. 分镜 9：仓库页停留 → 终端 pytest 全绿 → 收尾词

## 四、备注（口径与取舍，如实）

- **断网演示用控制台通道**：QQ 链路依赖 Pi 侧 NapCat ↔ 腾讯云 ↔ 手机三段外网，电脑拔网即断；控制台走本机回环 + 本地大模型，拔网照常。
- **儿童锁可降级**：完整版（双账号三连）优先，双账号不便时用简化版（主账号拒绝 + 物理开关），口播同步删儿童锁两句。
- **空调为演示件**：HA 侧 generic_thermostat 造的"演示空调"，温度设定可演示（真机实测 7→26.0）；其 state 联动受演示件传感器配置限制，镜头对准**温度数值变化**即可。
- **家电控制走云端路由**（可靠性优先取舍）：断网时家电控制暂不可用（对话/搜索等本地能力不受影响）——故分镜 6 断网段**只演示对话**；技术方案 Known Limitations 已同步披露。
- **测试数口径**：口播与字幕以录制日实测为准（本稿写 1862，若录制前基线增长，按当日 `python -m pytest -q` 实测念）。
