## 六、分步操作流程

1. 注册账号（ccopyright.com.cn）→ 实名认证（人脸 + 手机验证）
2. 选"计算机软件著作权登记申请"（普通登记，个人可自助）
3. 在线填表：按本文 §三/§四 逐项填写（信息提前备好，一次性填完）
4. 上传材料：源代码 PDF + 说明书 PDF（按平台格式提示核对）
5. 提交 → 在线缴费（个人官费按当期标准，缴费后出受理号）
6. 等待受理 → 补正（如有）→ 发证（当前周期约 30-60 个工作日，
   以平台公示为准）

## 七、常见坑（核对清单）

- [ ] **名称一致性**：软件全称与两份 PDF 封面逐字一致（含"小橘3号"
      的写法——阿拉伯数字 3）
- [ ] **版本号一致性**：登记版本 = 材料封面版本（V1.0），别填成开发
      版本 1.0.3
- [ ] **日期自洽**：开发完成日期 ≤ 首次发表日期（若填已发表）；
      开发完成日期与说明书内容覆盖期不矛盾
- [ ] **截图清晰度**：说明书截图须可辨识（已机验 63 页含图）
- [ ] **页数规格**：源代码每页 50 行、前后各 30 页（已满足）
- [ ] **申请表信息与材料信息交叉核对**：填完打印预览逐项对一遍材料
- [ ] **发表状态勾选**：GitHub release 公开 ≠ 一定算"已发表"（口径
      按平台提示；拿不准选与材料一致性更强的"未发表"并咨询确认）
