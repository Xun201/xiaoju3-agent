# 小橘3号 系统支持说明

> 2026-10-30 · 针对"银河麒麟 V10 SP1 运行 Windows 安装包白屏"问题的官方口径

## 一句话结论

**小橘3号 PC 端（.exe 安装包）是纯 Windows 应用，不能直接安装或运行在银河麒麟（Linux）系统上。** 白屏不是安装包坏了，是系统不兼容，请停止在这台麒麟机器上继续尝试安装。

## 为什么白屏

1. **安装包本身就是 Windows 专属格式**：`.exe` 安装器由 Inno Setup 制作，是 Windows PE 程序——麒麟（Linux 内核）没有能直接运行它的环境，双击后即使弹出界面也只是兼容层勉强渲染的空壳，看不到字是必然结果。
2. **小橘本体深度绑定 Windows 组件**：
   - 桌面窗口依赖 **WebView2 Runtime**（微软官方 Windows 组件，Linux 上不存在，Wine 下也无法正常注册）；
   - 后端链接 pythonnet/.NET 绑定、Windows 心跳/单实例互斥体/托盘等系统机制。

## 各平台支持现状

| 平台 | 支持状态 | 说明 |
|---|---|---|
| Windows 10/11 x64 | ✅ 官方支持 | 唯一完整体验（桌面窗+QQ+全部能力） |
| 麒麟/Linux 原生 | ❌ 不支持 | exe 无法运行，请勿继续尝试 |
| 麒麟/Linux + Wine | ⚠️ 不承诺 | 白屏即缺字体+缺 WebView2，不可作为主力环境 |
| 手机（Android） | ✅ 同网可用 | 小橘 APK 连局域网/Tailscale 内的后端 |
| 任意现代浏览器 | ✅ 同网可用 | 直接访问控制台网页版（见下） |

## 零成本替代方案（不装任何东西）

只要麒麟机器和运行小橘的 Windows 主机在**同一网络**（局域网或 Tailscale），打开浏览器访问：

```
http://<Windows主机IP>:5003/console
```

即可使用完整控制台（对话/待办/工具面板）——小橘的界面本来就是 Web 形态，浏览器就是天然跨平台客户端。

## 未来计划（已登记待办 #366 P3）

若未来确需在麒麟（Linux/ARM/龙芯）上**常驻**小橘后端，有两条评估路线（尚未启动，等需求确认）：
