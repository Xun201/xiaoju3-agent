# 小橘3号 · UI 设计需求文档

> 版本：v0.2 | 更新：2026-10-04
> 用途：外包/协作 UI 设计的参考清单
> 联系人：项目主理人（请通过仓库 Issues 联系）

---

## 一、项目简介

**小橘3号**（xiaoju3-agent）是一个**家庭私人 AI 智能体**：

- 跑在用户自己的 Windows 电脑上（有 Linux/ARM 移植版）
- 能聊天、记事、控家电、管待办、语音交互
- 有**桌宠**（小狐狸形象）+ **控制台**（Web UI）+ **QQ 机器人** 三个入口
- 核心卖点：**本地优先、数据私有、灵魂可迁移、四级权限**

## 二、视觉基调

| 维度 | 要求 |
|---|---|
| 主色调 | 橘色系（呼应"小橘"），温暖、亲切 |
| 辅助元素 | 狐狸、尾巴、爪印等可爱元素（克制使用） |
| 气质 | 温馨家庭助手，不是冷硬工业软件 |
| 参考风格 | Claude / ChatGPT 控制台的简洁 + Shimeji 桌宠的活泼 |
| 深浅模式 | 需要两套（当前只有浅色） |

## 三、交付格式

- **设计稿**：Figma（首选）/ Sketch / 或直接 SVG + PNG
- **图标**：SVG（线性图标统一 stroke 宽度与圆角）
- **桌宠**：透明底 PNG（256/512/1024 三档）+ 可选 Lottie 动画
- **命名规范**：`模块-元素-状态.扩展名`（如 `pet-idle-01.png`）

## 四、UI 缺口清单

### 模块 1：桌宠形象（最高优先级）

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 透明 PNG | 带背景占位图 | 抠干净的透明底，三档尺寸 | 设计 |
| 表情状态包 | 单一静态形象 | 待机/思考/说话/开心/出错 五种，每 2-3 帧 | 设计+动画 |
| 拖拽回弹 | 有基本弹回 | 更自然的物理缓动曲线 | 前端 |
| 右键菜单 | 无 | 右键桌宠出快捷菜单（静音/换装/退出） | 设计+前端 |

### 模块 2：控制台视觉系统

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 图标系统 | 风格不统一 | 一套线性图标，覆盖 15+ 场景 | 设计 |
| 配色方案 | 浅色为主 | 完整深浅两套主题 + 色板变量表 | 设计 |
| 字体层级 | 较随意 | 5 级字阶（标题/正文/辅助/标签/数字） | 设计 |
| 空状态 | 多处纯文字 | 统一空状态插画模板（无数据/无网络/出错） | 设计 |

### 模块 3：首次运行引导（Onboarding）★重要

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 欢迎页 | 无（首装引导被跳过） | 品牌欢迎页 + 3 步引导 | 设计 |
| API Key 配置 | 手改 .env | 图形化输入框 + 测试连接按钮 | 设计+前端 |
| 硬件自检 | 纯文字日志 | 可视化自检卡（逐项打勾/打叉） | 设计+前端 |
| 首启完成页 | 无 | 引导用户进入第一个对话 | 设计 |

> **背景**：当前首装引导体验缺失，用户装完不知道下一步干什么。

### 模块 4：设置面板 ★重要

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 设置入口 | 无（需手改 .env） | 控制台右上角齿轮 → 设置面板 | 设计+前端 |
| 分类导航 | 无 | 左侧分类（基础/权限/家居/通知/高级） | 设计 |
| 表单控件 | 无 | 统一表单样式（输入框/开关/下拉/滑块） | 设计 |
| 保存反馈 | 无 | 保存成功/失败 toast | 设计+前端 |

> **背景**：当前所有配置改 .env 文件，是体验硬伤。

### 模块 5：权限可视化 ★重要

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 当前等级 | 只显示在菜单文字 | 显眼徽章（头像旁显示 Lv.X） | 设计 |
| 等级说明 | 无 | 点击徽章弹出等级说明卡（各级能干什么） | 设计 |
| 升权引导 | 无 | "如何升级"提示（/register /coder_auth 等） | 设计 |

> **背景**：四级权限是核心卖点，但用户看不到、不懂。

### 模块 6：记忆管理界面 ★重要

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 记忆列表 | 无（存在 DB） | 卡片列表（时间/内容/来源） | 设计+前端 |
| 搜索/筛选 | 无 | 关键词搜索 + 时间筛选 | 前端 |
| 编辑/删除 | 无 | 单条编辑、批量删除 | 设计+前端 |
| 导出 | 无 | 导出为 JSON / Markdown | 设计 |

> **背景**：长期记忆是核心功能，现在无法查看/编辑。

### 模块 7：待办卡片

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 分区标题 | 简单横线+文字 | 精致分隔（图标/数量徽章） | 设计 |
| 优先级下拉 | 功能完成，样式朴素 | 更好交互 + P0-P5 颜色区分 | 设计+前端 |
| 勾选动画 | 打钩即划线 | 划线+淡出+勾选弹跳 | 前端 |
| 空状态 | "暂无待办" | 插画 + 引导文案 | 设计 |

### 模块 8：思维链 / 消息区

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 思维链卡片 | 折叠展开可用 | 精致动效 + 步骤可视化 | 设计+前端 |
| 思考中状态 | 文字提示 | 打字机/脉冲点动效 | 前端 |
| 错误态 | 文字直白（如 401） | 友好卡片（图标+人话+建议） | 设计+前端 |
| 消息气泡 | 基本可用 | 优化气泡尾巴/时间戳/状态角标 | 设计 |

### 模块 9：系统状态卡片

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 进度条 | 三档变色 | 渐变/圆角/动画 | 设计 |
| 温度显示 | "暂无温度" | 空状态插画 | 设计 |
| 数据可视化 | 纯数字+条 | 迷你趋势图（CPU/内存历史） | 前端 |
| 家居卡片 | 无 | 显示已连设备数/状态 | 设计 |

### 模块 10：更新通知 ★

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 版本检查 | 无 | 启动时静默检查，有新版出提示 | 前端 |
| 更新提示 | 无 | 角落弹窗 + 跳转下载页 | 设计 |
| 更新日志 | 无 | 控制台内可查版本历史 | 设计+前端 |

### 模块 11：托盘 / 系统级交互 ★

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 托盘菜单 | 基础功能 | 优化菜单（分组/图标/快捷键提示） | 设计 |
| 通知气泡 | 系统默认 | 品牌化通知（狐狸头像 + 橘色调） | 设计 |
| 快捷键 | 无 | 定义常用快捷键（呼出控制台/静音/截图） | 设计 |

### 模块 12：安装器 UI（Inno Setup）

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 欢迎页 | 默认 Inno 样式 | 品牌化欢迎页 | 设计 |
| 组件页 | 三类型下拉 | 卡片式选择 | 设计+脚本 |
| 完成页 | 默认文字 | 带图标 + 下一步引导 | 设计 |

### 模块 13：响应式 / 高 DPI / 无障碍

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 小屏适配 | 固定宽度 | <1200px 卡片折叠/堆叠 | 前端 |
| 高 DPI | 缩放可能模糊 | 图标/桌宠用矢量或多倍图 | 设计 |
| 键盘导航 | 无 | Tab 键可遍历所有可交互元素 | 前端 |
| 屏幕阅读器 | 无 | 语义化标签 + ARIA | 前端 |

### 模块 14：国际化（长期）

| 项 | 现状 | 期望 | 类型 |
|---|---|---|---|
| 多语言 | 全中文 | i18n 框架 + 中/英切换 | 前端 |

## 五、优先推荐

### 如果只挑三样（感知最强）

1. **桌宠透明 PNG + 状态包** —— 最有辨识度，用户第一眼就看到
2. **首次运行引导** —— 决定用户留存，现在完全缺失
3. **设置面板** —— 改配置不用再碰 .env

### 如果挑五样

4. **图标系统统一** —— 1-2 天出整套，收益面广
5. **权限可视化** —— 四级权限是卖点，必须让用户看见

### 完整优先级排序

| 级别 | 模块 |
|---|---|
| P0 | 桌宠形象、首次运行引导、设置面板 |
| P1 | 权限可视化、记忆管理界面、图标系统 |
| P2 | 待办卡片优化、思维链动效、更新通知 |
| P3 | 托盘交互、安装器 UI、深浅主题 |
| P4 | 响应式、无障碍、国际化 |
